# Student Portal 🎓

A web-based Student Portal developed using PHP, MySQL, HTML, CSS, and JavaScript.

This project provides a simple platform for managing student information and presenting student-related services.

## ✨ Features

- Student Registration
- Student Information Management
- View Student Details
- Edit Student Information
- Delete Student Records
- Courses and Services Pages
- Form Validation
- Interactive User Interface

## 🛠️ Technologies Used

- **PHP** – Backend Development
- **MySQL** – Database Management
- **HTML5** – Page Structure
- **CSS3** – Styling and Layout
- **JavaScript** – Interactive Features

## ⚙️ Installation and Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from XAMPP.
4. Open phpMyAdmin and create/import the `student_portal.sql` database.
5. Copy `db.example.php` and rename the copy to `db.php`.
6. Update the database connection details in `db.php`.
7. Open the project in your browser:

```text
http://localhost/student-portal/
```
